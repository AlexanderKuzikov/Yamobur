<h1 align="center">Yamobur</h1>
<p align="center">Лендинг услуги ямобура-вездехода</p>

---

Одностраничный лендинг услуги ямобура-вездехода. Чистый статический HTML без зависимостей и сборочных инструментов.

- **Лендинг** — одностраничная презентация услуги.
- **Статика** — чистый HTML, без JS-фреймворков.
- **Zero deps** — отсутствие каких-либо зависимостей.

## Быстрый старт

```bash
git clone https://github.com/AlexanderKuzikov/Yamobur.git
cd Yamobur
```
