## 2026-08-11: Статик-сайт вместо Joomla-сохранёнок

**Контекст:** Имеются полные Joomla-сохранёнки (5 разделов, ~280 КБ HTML каждая, с CSS/JS мусором фреймворков). Нужен готовый сайт для деплоя на yamobur-vezdehod.ru.

**Решение:** Собрать чистый статик в `site/`: 11 страниц (лендинг + 4 раздела + 6 статей), один общий CSS, zero deps, системные шрифты. Контент — из сохранёнок; тексты 5 статей восстановлены из Wayback (в сохранёнках только заголовки). Статьи — отдельными страницами (`stati/*.html`) с латинскими URL для SEO. Изображения — только уникальные (17 шт.), без дублей из `*_files/`. Метрика 34616285, robots.txt, sitemap.xml. URL статей/страниц латиницей, русские имена сохранёнок не используются.

**Альтернативы:**
1. Залить сохранёнки как есть — ~11 МБ мусора, дубли CSS/JS, нерабочие ссылки на рф-домен, кривые URL.
2. PHP file-router (как Zavodsvay-Static) — лишняя зависимость для чистой статики.

**Trade-off:** Ручная переноска контента (риск потери актуальности статей 2016–2020 из Wayback) против чистоты и деплой-готовности. Отсутствие главной в сохранёнках закрыто сборкой лендинга из фактических данных (техника, цены, работы, контакты).

## 2026-08-12: Главная v2 — три самодостаточных концепта-черновика

**Контекст:** Текущая главная (v1, индустриальный минимализм) перегружена текстом, эмодзи-иконки выглядят дёшево, нет отличия от конкурентов. ТЗ `qwen38-home-design-v2.md` запросило 3 визуально несхожих альтернативы.

**Решение:** Каждый концепт — один самодостаточный HTML со встроенным CSS (без общего `css/style.css`): «Приборная панель» (`site/v2-dashboard.html`), «Конструктивистский плакат» (`site/v2-poster.html`), «Полевой репортаж» (`site/v2-field.html`). Файлы лежат рядом с `img/` для локального просмотра, но это черновики: в sitemap.xml/robots.txt не добавлены, `index.html` не заменяют до выбора варианта. Контент, цены, ТТХ, контакты, SEO-head, Метрика 34616285 — без изменений; эмодзи заменены инлайн-SVG; бургер-меню на checkbox без JS; адаптив 960/720.

**Альтернативы:**
1. Точечно править текущий `index.html` — не даёт качественной смены образа.
2. Общая CSS-тема для концептов — связала бы руки при сравнении и выборе.

**Trade-off:** Дублирование разметки в 3 файлах против полной автономности каждого варианта (одноразовые черновики, цена приемлемая). После выбора концепт переносится в `index.html` (при необходимости — в общий css/style.css), остальные v2-файлы удаляются.
